# Tavole del pannello v3 (approvate da Dario il 6/10/2026)

Riferimento per aspetto, misure e disposizione del pannello v3; le regole sono in [`../UI-DESIGN-SYSTEM.md`](../UI-DESIGN-SYSTEM.md). I dati sono inventati: codici pezzo, ordini, grigliati e allarmi servono solo a riempire le pagine. La geometria del cassetto (819 × 605 mm, 4 × 13 tasche 40 × 110, passo 58 × 134) è ricavata dal disegno del pannello di oggi; nel pannello vero arriva dai dati di cassetto e grigliato. L'accento è il blu cobalto `#4D9BFF`.
